# Gemini & Agent Guidelines

Refer to [AGENTS.md](file:///C:/projects/groshe/AGENTS.md) for complete project guidelines and agent commit policies.

### Key Rules
- **Commit Size:** Keep additions/modifications to ~300 lines per commit. No limit on deletions. No giant commits.
- **Commit Messages:** Must explain (1) what changed, (2) why/rationale, and (3) how it was tested.
- **Verification:** Ensure `cargo check --workspace` and tests pass before committing.
